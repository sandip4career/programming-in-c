# Programming in C

Welcome to the **Programming in C** repository! This is a comprehensive collection of C programming examples, exercises, and foundational concepts designed to help beginners and intermediate developers master the C language.

## 🚀 Overview

This repository contains over 110+ C programs covering everything from basic syntax to advanced data structures and file handling. It serves as a personal workbook and a practical reference guide for logic building.

## 📂 What's Inside?

The programs in this repository cover a wide range of topics, including:
* **Basic Concepts:** Input/output operations, formatting, arithmetic, and operators.
* **Control Flow:** Conditional statements (`if-else`, `switch-case`) and loops (`for`, `while`, `do-while`).
* **Functions & Recursion:** Modular programming and solving problems recursively (e.g., Fibonacci, Sum of natural numbers).
* **Arrays & Matrices:** 1D arrays, 2D arrays, matrix addition, and matrix multiplication.
* **Pointers:** Introduction to pointers, pointer applications, function pointers, and special pointers (`void`, `null`, `dangling`, `wild`).
* **Strings:** String manipulation with and without predefined library functions.
* **Structures & Unions:** Creating custom data types and utilizing bit-fields.
* **File Handling:** Reading and writing files using different methods (`fscanf`, `fread`, `fwrite`, `fputs`, `fprintf`).
* **Data Structures:** Linear data structures like Linked Lists and custom logic algorithms.
* **Patterns:** Fun logic-building programs including Floyd's triangle, star patterns, and number patterns.
